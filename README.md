# VK Dating AutoClicker

Расширение для `https://vk.ru/dating` и `https://vk.com/dating`. Запускает автокликер лайков одним нажатием на иконку браузера.

Версия расширения: **`1.0.0.0`**. Источник версии для сборки и релиза — [`src/manifest.json`](./src/manifest.json).

## Возможности

- Поддерживает приложение знакомств с ID `7058363` на доменах `*.pages-ac.vk-apps.com` и `*.pages.vk-apps.ru`.
- Запускается и останавливается нажатием на иконку: красная — готов к запуску, зелёная — работает, серая — требуется проверка страницы.
- По серой иконке открывает диагностику с причиной недоступности и кнопкой «Проверить снова».
- Во время работы нажимает «Пропустить», «Не сейчас» и «Продолжить» у предложений внутри приложения. Текст самого предложения не важен; пропуски не увеличивают счётчик лайков.
- Выбирает доступные кнопки, исключая скрытые, заблокированные и перекрытые элементы. Не запускается при неоднозначном выборе iframe.
- Проверяет адрес вкладки перед каждым действием и останавливается при уходе со страницы знакомств.
- Показывает счётчик переходов между анкетами на иконке и поверх страницы. Панель скрывается, если навести на неё курсор.
- После трёх подряд неудачных попыток останавливается вместо бесконечного повторения кликов.

Счётчик подтверждает устойчивую смену имени с возрастом и основного фото после клика. Он использует интерфейс, а не ответ API, поэтому не гарантирует принятие лайка сервером. Если имя с возрастом или фото не изменились, лайк не засчитывается. Фото выбирается из карточки с доступной кнопкой, а не из предзагруженной следующей анкеты.

Предложения пропускаются только при включённом кликере. Если после пропуска возвращается та же анкета, неподтверждённый лайк сбрасывается без увеличения счётчика и без ожидания таймаута 1600 мс.

## Установка и запуск

1. Скачайте исходники или распакуйте ZIP из релиза.
2. Откройте `chrome://extensions` или `edge://extensions` и включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение». В исходниках выберите папку `src/`; в распакованном релизном ZIP — папку с `manifest.json`.
4. Обновите вкладку VK, откройте раздел «Анкеты» с фотографией и кнопками реакций.
5. Нажмите красную иконку для запуска. Для остановки нажмите зелёную.

После обновления файлов расширения перезагрузите его на странице расширений, затем обновите вкладку VK. При серой иконке нажмите на неё: диагностика покажет причину. Проверьте версию `1.0.0.0` и доступ расширения к сайтам VK.

В релиз также входит подписанный CRX — расширение одним файлом.

## Тайминги

Все задержки указаны в миллисекундах. Значения находятся в `config` файла [`src/content.js`](./src/content.js).

| Параметр | Значение |
| --- | --- |
| `reaction` | `like` |
| `minDelay` / `maxDelay` | `0` / `8` |
| `retryDelayMin` / `retryDelayMax` | `60` / `100` |
| `confirmMinDelay` | `60` |
| `confirmStableDelay` | `60` |
| `confirmTimeout` | `1600` |
| `maxFailures` | `3` |
| `maxClicks` | `Infinity` |

После пропуска предложения дополнительной задержки нет. Если предыдущий лайк ещё ожидает подтверждения, применяется то же окно устойчивости анкеты в 60 мс, что и при обычной смене. Фактическая скорость зависит от загрузки и анимаций сайта; одновременно ожидается подтверждение только одного лайка.

## Проверки

Для локальных проверок нужен Node.js `22+`. Зависимости для тестов не требуются:

```powershell
npm.cmd test
```

Тесты проверяют распознавание анкет, доступность кнопок, пропуск предложений, тайминги, диагностику и взаимодействие с Chrome API на имитации DOM. Проверка реальной страницы VK выполняется отдельно.

## Локальная сборка

Установите зависимости и укажите путь к PEM-ключу подписи:

```powershell
npm.cmd ci
$env:CRX_KEY_PATH = Join-Path $PWD 'privatekey.pem'
npm.cmd run pack
```

Результат:

- `dist/vk-dating-autoclicker-1.0.0.0.crx`
- `dist/vk-dating-autoclicker-1.0.0.0.zip`

Приватные ключи, `dist/` и `node_modules/` исключены из Git. Сохраните ключ для последующих сборок с той же подписью.
